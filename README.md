# Knox

Marketing site for **Knox** — parent security company for [Web5 Audit](https://audit.web5.nexus/) and upcoming tools (site hardening, agent guardrails, and more).

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Hero art

`public/hero/fort-knox.jpg` is a custom hybrid render: solid stone vault on the left transitioning into a blue wireframe/blueprint on the right, with reflective ground — matching the Knox marketing mock.
